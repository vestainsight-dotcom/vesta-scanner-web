# Community Plan / 社群規劃

> **Status: proposal.** GitHub Discussions are **not enabled yet**. This document describes the planned categories so they can be reviewed before the repository is published.
>
> **狀態：提案。** GitHub Discussions **尚未啟用**；本文件說明預計的分類，供儲存庫公開前審閱。

## Where things go / 該在哪裡提出

| You want to… / 你想… | Use / 使用 |
|---|---|
| Suggest an idea or ask "would this be useful?" / 提出想法 | Discussion → **Ideas** |
| Discuss a research question or method / 討論研究問題或方法 | Discussion → **Quant Research** |
| Ask how something works / 詢問運作方式 | Discussion → **Q&A** |
| Share a prototype or experiment / 分享原型或實驗 | Discussion → **Show & Tell** |
| Report a reproducible bug / 回報可重現的錯誤 | Issue → Bug report |
| Track an agreed feature / 追蹤已確認的功能 | Issue → Feature request |
| Formalize a research proposal / 正式提出研究提案 | Issue → Research proposal |
| Report a vulnerability / 回報漏洞 | **Privately** — see [SECURITY.md](../SECURITY.md) |

## Proposed Discussion categories / 預計的討論分類

### 💡 Ideas
Product suggestions, new dashboard features, user-experience improvements.
產品建議、新的儀表板功能、使用體驗改進。
*Format: open discussion.*

### 📐 Quant Research
Volume anomalies, market structure, BTC correlation, relative strength, independent movers, research methodology. Posts should state the question, the data needed and how a result could be validated. Discussion of methods is welcome; trade calls and price predictions are not.
成交量異常、市場結構、BTC 相關性、相對強弱、獨立走勢幣種、研究方法。請說明研究問題、所需資料與驗證方式；歡迎討論方法，但不接受喊單或價格預測。
*Format: open discussion.*

### 🙋 Q&A
Setup questions, architecture, mock data, contribution workflow.
安裝設定、架構、模擬資料、貢獻流程。
*Format: question/answer (an answer can be marked as accepted).*

### 🎨 Show & Tell
Community prototypes, visualizations, research experiments built on this demo. Use simulated or public data only.
社群原型、視覺化、基於本展示的研究實驗；僅限模擬或公開資料。
*Format: open discussion.*

### 📣 Announcements
Releases, roadmap updates, community milestones. Only maintainers can post; everyone can comment.
版本發布、路線圖更新、社群里程碑；僅維護者可發文，所有人可留言。
*Format: announcement.*

## Labels (planned) / 預計的標籤

| Label | Meaning |
|---|---|
| `good first issue` | Small, well-defined starter task / 適合新手 |
| `help wanted` | Maintainers would welcome a contribution / 歡迎協助 |
| `bug` | Something does not work as documented / 錯誤 |
| `enhancement` | Improvement to existing behaviour / 改進 |
| `research` | Research proposal or question / 研究 |
| `ui` · `a11y` · `i18n` · `pwa` · `mock-data` · `docs` | Area / 領域 |
| `schema` | Touches a public data contract; Discussion required / 涉及公開資料合約 |
| `needs-triage` | Not yet reviewed by a maintainer / 待分類 |
| `out-of-scope` | Outside the boundaries in CONTRIBUTING.md / 超出範圍 |

## Moderation / 管理原則

- The [Code of Conduct](../CODE_OF_CONDUCT.md) applies to every space.
- Research discussion focuses on methods and evidence, not on people.
- Posts that look like investment advice, promotion or pump attempts are removed.
- Secrets or personal data posted by mistake are deleted, and the poster is notified.

## Setup checklist (for maintainers, before publication) / 公開前維護者檢查清單

- [ ] Enable Discussions and create the five categories above
- [ ] Create the labels above
- [ ] Enable private vulnerability reporting (see SECURITY.md)
- [ ] Confirm the Code of Conduct enforcement contact
- [ ] Create the starter issues from [GOOD_FIRST_ISSUES.md](GOOD_FIRST_ISSUES.md)
